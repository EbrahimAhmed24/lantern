# Contributing Guidelines

Thank you for contributing to Lantern!

## Branch Naming

Use descriptive branch names:

- `feature/` for new features.
- `fix/` for bug fixes.
- `docs/` for documentation updates.

## Commit Messages

Follow the conventional commit format:

`type(scope): description`

Examples:

- `feat(tasks): add task filtering`
- `fix(storage): handle missing files`
- `docs(readme): update usage instructions`

## Pull Requests

- Create pull requests from short-lived branches.
- Explain what changed and why.
- Reference the related issue using `Closes #issue-number`.
- Request a review from the other team member.
- Resolve review comments before merging.

## Code Style

- Use clear and descriptive names.
- Follow standard Python conventions.
- Keep functions focused and readable.
